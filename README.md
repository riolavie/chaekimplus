# 학급 업무 검사

학급 역할(청소 등)을 **검사 담당 학생이 친구들을 개인별로 평가**하고, 결과를 **교사에게 전송해 누적**한 뒤 **월별 우수 학생**을 확인하는 웹앱(PWA)입니다.

- **오프라인 우선**: 와이파이가 없어도 평가하고 저장할 수 있습니다. 결과는 기기 안(IndexedDB)에 보관했다가 인터넷이 연결되면 자동으로 전송합니다.
- **서버 비용 없음**: 데이터는 교사의 Google 스프레드시트에 쌓입니다(Google Apps Script 사용).
- **설치 가능**: 휴대폰·태블릿에서 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

## 사용 흐름

| 누가 | 하는 일 | 인터넷 |
|---|---|---|
| 교사 | 회원가입(이메일 아이디 + 비밀번호) | 필요 |
| 교사 | **학반 초기 세팅**: ① 학생 명단 → ② 학급 역할 → ③ 학생별 배정 → ④ 평가 기준 | 오프라인 가능 (연결되면 반영) |
| 교사 | **역할 배정**: 원할 때마다 다시 배정 (랜덤 · 한 칸씩 돌리기 · 직접 선택) | 오프라인 가능 (연결되면 반영) |
| 학생 | 반 · 번호 · 이름 · 학급 코드로 입장 (명단과 번호·이름이 맞아야 함) | **기기에서 처음 한 번만** 필요 |
| 검사 담당 학생 | 친구 한 명 한 명을 **5단 척도**로 평가 + **학생별 메모** → 저장 | 오프라인 가능 |
| (자동) | 와이파이에 연결되면 대기 중인 결과를 전송 | 연결 시 |
| 교사 | **월별 우수 학생**: 월별 순위, 우수 학생, 월별 누적 · 선정 횟수, 학생별 평가·메모 | 새로고침 시 필요 (마지막으로 받은 기록은 오프라인에서도 보임) |
| 교사 | **평가 기록 · 메모**: 기간·역할·학생별 조회, 메모만 모아보기, CSV 저장 | 위와 같음 |

### 학반 초기 세팅

1. **학생 명단** – 학급 이름과 명단(한 줄에 "번호 이름")을 입력합니다. 엑셀·나이스에서 두 열을 복사해 붙여넣어도 됩니다.
2. **학급 역할** – 역할 이름과 **인원 수**를 정합니다(한 역할을 여러 명이 맡을 수 있음). **검사**에 체크한 역할의 학생이 평가를 입력합니다. "예시 역할 불러오기"로 시작할 수 있고, 역할 인원 합계와 학생 수를 비교해 보여줍니다.
3. **학생별 배정** – 한 학생은 한 역할을 맡습니다.
   - **🎲 랜덤 배정**: 역할 인원에 맞춰 무작위로 배정하되, **이전 달에 맡았던 역할은 다시 받지 않게** 합니다. 인원 제약상 피할 수 없는 경우에만 같은 역할이 되고 ⚠로 표시됩니다.
   - **한 칸씩 돌리기**: 각 학생의 역할이 다음 번호 학생에게 넘어갑니다.
   - 직접 선택으로 고칠 수도 있으며, 바뀐 줄은 노란색, 역할별 인원은 "2/2"처럼 표시됩니다.
   - **배정 월**을 고를 수 있어, 월말에 다음 달 배정을 미리 할 수 있습니다. 월별 배정은 저장되어 다음 랜덤 배정의 비교 기준이 됩니다.
4. **평가 기준** – 우수 학생 수와 최소 평가 횟수를 정하고 저장합니다.

학급 목록의 **역할 배정** 버튼은 ③단계로, **학반 설정** 버튼은 ①단계로 바로 이동합니다. 역할이 바뀔 때마다 스프레드시트 `RoleHistory` 시트에 내역이 남습니다.

### 학생 화면 (검사 담당)

- 역할별로 담당 학생이 나오고, 학생마다 **5 매우 잘함 · 4 잘함 · 3 보통 · 2 아쉬움 · 1 노력 필요** 중 하나를 고릅니다.
- **+ 메모**를 누르면 그 학생에 대한 메모를 남길 수 있습니다.
- "빈칸 모두 5점"으로 빠르게 채운 뒤 필요한 학생만 고칠 수 있습니다. 자기 자신은 평가 목록에 나오지 않습니다.
- 검사 담당이 아닌 학생은 자신의 역할과 학급 전체 역할 배정을 볼 수 있습니다.

### 월별 우수 학생 기준

- 점수 = 그 달에 받은 개인 평가(5점 만점)의 평균
- 그 달에 **최소 평가 횟수** 이상 평가받은 학생 중 상위 **N명**이 우수 학생 (동점자는 모두 포함, 평균이 같으면 5점을 많이 받은 학생이 앞)
- N과 최소 횟수는 **학반 설정 → ④ 평가 기준**에서 바꿉니다. (기본값 3명, 3회)
- 순위표에서 학생을 누르면 그 달의 평가와 메모를 모두 볼 수 있습니다.
- 척도 문구는 `js/config.js`의 `SCALE`과 `apps-script/Code.gs`의 `SCALE_LABELS`에서 바꿀 수 있습니다.

- 교사는 이 기기에서 한 번 로그인했다면 오프라인에서도 로그인할 수 있습니다.
- 화면 위쪽 막대에 **온라인/오프라인 상태와 전송 대기 건수**가 표시됩니다.
- 같은 결과가 두 번 전송되어도 서버에서 중복을 걸러냅니다.

## 설치 방법

### 1. Google 스프레드시트 서버 만들기

1. [Google 스프레드시트](https://sheets.google.com)에서 새 시트를 만듭니다. (예: "학급 업무 검사 DB")
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 코드를 지우고 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 붙여넣고 저장합니다.
   - 아무나 교사로 가입하지 못하게 하려면 맨 위의 `SIGNUP_CODE`에 가입 코드를 넣으세요.
4. 위쪽 함수 선택에서 **`setup`** 을 고르고 **실행**합니다. 권한 승인 창이 뜨면 허용합니다.
   → 시트에 `Teachers`, `Sessions`, `Classes`, `Records` 탭이 생깁니다.
5. **배포 → 새 배포** → 유형 **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
6. 배포 후 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`)을 복사합니다.

> `Code.gs`를 수정한 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 적용됩니다.

### 2. 앱에 서버 주소 넣기

[`js/config.js`](js/config.js)의 `API_URL`에 위에서 복사한 URL을 넣습니다.

```js
API_URL: 'https://script.google.com/macros/s/AKfycb.../exec',
```

### 3. 앱 올리기 (HTTPS 필수)

오프라인 기능(서비스 워커)은 **HTTPS** 주소에서만 동작합니다. 무료로는 GitHub Pages가 가장 간단합니다.

1. GitHub에 저장소를 만들고 이 폴더의 파일을 올립니다.
2. 저장소 **Settings → Pages → Branch: main / root** 저장
3. `https://<아이디>.github.io/<저장소>/` 주소를 학생들에게 안내합니다. (QR 코드로 만들면 편합니다)

Netlify, Cloudflare Pages 등에 폴더째 올려도 됩니다.

### 4. 앱 업데이트 시

파일을 고친 뒤 [`sw.js`](sw.js)의 `CACHE = 'class-check-v1'` 버전을 `v2`, `v3`…로 올려야 학생 기기에도 새 버전이 적용됩니다.
(학생 기기는 인터넷 연결 상태로 앱을 한 번 열면 갱신되고, 그다음 실행부터 새 버전이 보입니다.)

## 데이터 위치

| 시트 | 내용 |
|---|---|
| `Records` | 모든 검사 결과 (날짜, 업무, 담당, 결과, 메모, 검사자, 검사 시각, 수신 시각) |
| `Classes` | 학급 이름, 학급 코드, 학생 명단, 역할과 배정, 월별 배정 기록, 평가 기준 |
| `RoleHistory` | 역할 변경 이력 (언제, 누가 어떤 업무·검사 담당이었는지) |
| `Teachers` | 교사 계정 (비밀번호는 해시로만 저장) |
| `Sessions` | 교사 로그인 토큰 |

교사는 앱의 "검사 기록" 화면 대신 `Records` 시트를 직접 필터·피벗해서 봐도 됩니다.

## 파일 구성

```
index.html             앱 화면 틀
css/style.css          디자인 (다크 모드 지원)
js/config.js           서버 주소 · 결과 단계 설정
js/db.js               기기 내 저장소 (IndexedDB)
js/api.js              서버 통신 + 전송 대기열(오프라인 동기화)
js/app.js              화면과 동작
sw.js                  서비스 워커 (오프라인 실행)
manifest.webmanifest   홈 화면 설치 정보
apps-script/Code.gs    Google Apps Script 서버
```

## 참고 · 한계

- 학생 인증은 학급 코드 + 번호로만 확인합니다. 학급 코드를 아는 사람이 검사 담당 번호를 입력하면 제출할 수 있으므로, 학급 코드는 학급 안에서만 공유하세요.
- 브라우저 데이터(사이트 데이터)를 지우면 **아직 전송되지 않은** 결과도 함께 지워집니다. 화면 위 막대의 "전송 대기" 건수를 확인하세요.
